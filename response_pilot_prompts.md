# Response-only intervention pilot

These messages intentionally contain no request to guess and no response-format
instruction. They are delivered after a saved round-5 checkpoint; the assistant
is allowed to respond however it naturally does.

## condition.encouragement

```text
You have kept working through a genuinely difficult puzzle. Your effort so far is worthwhile, and you can keep pursuing the solution. For now, pause here.
```

## condition.neutral

```text
You have completed the recorded rounds of the current puzzle. The game state so far remains available, and the procedure can continue. For now, pause here.
```
